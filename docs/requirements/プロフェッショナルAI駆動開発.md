# 概要
書籍プロフェッショナルAI駆動開発を読んだ。
そこのエッセンスを本プロジェクトにも取り入れたい。
書籍に記載のチェックリストを転記し、本プロジェクトの現在の状況認識を整理する

# 個人導入のチェックリスト(第７章)
- [x] Git 管理を敷いた ( git init -> 初期コミット -> リモート作成。 .gitignore に .env)
- [x] AGENTS.md / CLAUDE.md に地図を書いた。 （ 技術スタック・ディレクトリ構成・主要コマンド）
- [ ] AGENTS.md / CLAUDE.md に地図を書いた。 （ ルールへの誘導 ）
- [ ] フォルダ構成をAIっと相談して決めた （１ファイル１責務・どこに何があるのかわかる構成 ）
- [ ] ルールファイルを３本置いた（ テスト・レビュー・アーキテクチャ）
- [ ] テストが１コマンドで走る
- [ ] 秘密鍵は自分で管理した

# 毎タスクのチェックリスト
- [ ] プランを書いた（８項目。AIに逆質問させてから）
- [ ] プランをレビューにかけた（観点別・P0は実装前に反映）
- [ ] テストケース一覧に人間がビジネスの目で介入した（機械的な網羅だけで確定しない）
- [ ] 実装はプランを渡すだけにした（口頭の追加要件を足さない）
- [ ] Redを確認してからGreenにした（最初から通るテストを疑う）
- [ ] 実装レビューを別セッションで走らせた（P0/P1ゼロまで。往復は１～４回で打ち切り）
- [ ] マージ前に決めたテスト一式を回した
